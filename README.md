# MO_LLM

**Programmer/Participants:** Zakaria Abdelmoiz DAHI :shipit:,  and Enrique Alba.

**About:** This repository contains the code for executing:

	- Optimisation of the energy, memory, time and precision of Large Language Models using a multi-objective optiser. 

**Code:** 
    - Folder MATERIALS contains a presentation of the proposal.
    - Folder CODE contains the code of LLMs (using Vidur simulator) optimised using NSGA-II (using pymoo).

**How to:** 
    - Install viudur LLM simulators: https://github.com/microsoft/vidur?tab=readme-ov-file
    - Activate the virtual environment: conda activate env
    - Launch main_pymoo.py.
    - Enjoy reading/analysing the ".json" and ".png" files generated.
